# Blood pressure analysis exercise

This repository contains fully synthetic data for a workshop on
AI-assisted clinical data analysis and computational reproducibility.
No real patient records are included.

## Study scenario

A simulated randomized study compares a structured blood-pressure
management program with usual care. Systolic blood pressure is
measured at baseline and after 12 weeks.

The aim is to compare 12-week blood pressure between the groups,
adjusting for baseline blood pressure.

## Files

- `bp_study.csv` — synthetic study data.
- `data_dictionary.md` — variable descriptions, units, and coding.

## Important

These data were generated solely for teaching. Results obtained from
them do not provide evidence about the effectiveness of any clinical
intervention.
